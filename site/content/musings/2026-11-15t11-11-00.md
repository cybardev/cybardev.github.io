> _Torvalds suggested adding an AGENTS.md file that makes generating kernel code expensive. He ends every session with a lengthy cleanup pass that takes a couple of hours to run, executing tasks like ensuring that the code matches the comments. That amount of work cannot be done with a free LLM account. I asked whether that risked cutting off bright new developers that we would rather hang onto; **Torvalds answered that the kernel project only wants serious developers. That includes having access to enough resources to function in this world.**_
