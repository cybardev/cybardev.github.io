[Typst](https://github.com/typst/typst) is fabulous. Use Typst.

Made a [marriage biodata template](https://github.com/cybardev/resume/blob/main/src/biodata.example.typ) yesternight. I like how I can code documents in a natural and intuitive language (unlike LaTeX) that feels similar to Markdown, but has functions, loops, and imports that allow you to make reusable components. And built-in styling so you don't need to worry about CSS.
